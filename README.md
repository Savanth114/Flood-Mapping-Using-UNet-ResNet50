# Flood Mapping Using U-Net with ResNet50

## Overview
This project implements a deep learning-based flood mapping system using a U-Net architecture with a ResNet50 encoder. The model performs semantic segmentation on satellite imagery to identify flood-affected regions.

## Features
* Flood area segmentation from satellite images
* U-Net architecture with ResNet50 backbone
* Deep learning-based semantic segmentation
* Satellite imagery analysis

## Technologies Used
* Python
* TensorFlow / Keras
* NumPy
* OpenCV
* Matplotlib

## Repository Contents
* `Unet_Resnet50.ipynb` – Training and evaluation notebook
* `Flood_mapping_article_final.pdf` – Research paper and project documentation

## Applications
* Disaster management
* Flood monitoring
* Environmental analysis
* Remote sensing
